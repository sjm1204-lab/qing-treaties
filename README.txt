청 말기 주요 조약 5선 — 배포용 폴더

이 폴더 안의 내용(index.html, assets 폴더, README.txt)을 저장소 맨 위에 그대로 올리면 됩니다.
index.html이 첫 화면입니다.

[GitHub Pages]
1. GitHub에서 Public 저장소를 만든다 (예: qing-treaties)
2. GitHub Desktop으로 저장소를 내려받고(Clone), 이 폴더 안의 내용을 저장소 폴더에 복사한 뒤
   Commit → Push 한다  (웹 업로드는 한 번에 100개 파일까지라 파일 317개를 한꺼번에 올릴 수 없음)
3. 저장소 Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
4. 1~3분 뒤 https://아이디.github.io/qing-treaties/ 로 접속
